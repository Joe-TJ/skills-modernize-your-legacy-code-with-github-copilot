## Coverage Notes

- The test cases above cover the current main menu flow, balance inquiry, credit, debit, insufficient funds handling, invalid input at the menu, and the non-persistent working-storage behavior.
- The current COBOL implementation does not include explicit validation for negative amounts or malformed numeric input, so those scenarios are not covered as approved business rules in this plan.
- When the Node.js version is created, these cases can be mapped to unit tests for balance arithmetic and integration tests for end-to-end menu and storage behavior.
